COMO EXECUTAR (na raiz do projeto)

  1) Uma vez so: criar o venv do backend e instalar o front
       python -m venv backend\.venv
       backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
       cd frontend && npm install

  2) Rodar tudo e gerar o relatorio
       backend\.venv\Scripts\python.exe tests\rodar_testes.py

     Relatorio: tests\relatorios\relatorio_testes.html
     (cada teste aparece como PASSOU ou FALHOU, com o detalhe da falha)

  Rodar so uma parte:
       backend\.venv\Scripts\python.exe -m pytest tests\backend\sprint1
       cd frontend && npx vitest run sprint2

Nao precisa do MySQL nem de SMTP: o get_db e trocado por SQLite em memoria
e o envio de e-mail e trocado por uma lista (fixture "emails").
