# Backup do tema local

Cópias dos três arquivos antes da adoção do tema global. Para restaurar,
execute `./restaurar.ps1` no PowerShell dentro desta pasta.
A restauração sobrescreve somente esses três arquivos com a versão salva;
se você os editar depois, preserve essas novas alterações antes de restaurar.
Não altera dependências, banco de dados ou outros arquivos.
